# 🌍 WorldView ### A real-time, immersive 3D geospatial intelligence platform right in your browser. [](LICENSE) []()
--- Welcome to **WorldView**—an interactive geospatial visualization engine designed to bring global signals, real-time data layers, and tactical telemetry into a single, explorable 3D globe. --- ## ✨ Quick Navigation * [🚀 Features](#-features) * [⚡ Quick Start](#-quick-start) * [🗺️ Live Data Layers](#️-live-data-layers) * [🔧 Project Architecture](#-project-architecture) * [📋 License](#-license) --- ## 🚀 Features * **🌐 Photorealistic 3D Globe:** Smooth navigation powered by modern WebGL and CesiumJS, complete with high-resolution terrain and spatial tiles. * **✈️ Real-Time Telemetry:** Track live aircraft transponders, global maritime vessels, and orbital satellites with true-to-life heading orientations. * **🕶️ Tactical Sensor Modes:** Instantly reskin your viewport with custom visual filters including NVG (Night Vision), FLIR/Thermal, and CRT aesthetics. * **📡 Interactive Contacts:** Click on any tracked asset to pull up live metadata, view trails, and inspect regional context. --- ## ⚡ Quick Start Get the project up and running locally in just a few steps: 1. **Clone the repository:** ```bash git clone https://github.com/froxyop-glitch/worldview.git cd worldview ``` 2. **Install dependencies:** ```bash npm ci ``` 3. **Run the development server:** ```bash npm run dev ``` 4. Open your browser and navigate to **`http://localhost:4173`**. --- ## 🗺️ Live Data Layers WorldView integrates multiple public and open data sources into distinct toggleable layers: | Layer | Description | Source | | :--- | :--- | :--- | | **✈️ Live Flights** | Global aircraft telemetry and historical paths | OpenSky & adsb.lol | | **🚢 Maritime Vessels** | Real-time global ship tracking and beacons | AISStream | | **🛰️ Satellites** | Orbital elements, trajectories, and constellations | CelesTrak | | **🌍 Earthquakes** | Recent global seismic activity | USGS | | **🔥 Active Fires** | Near real-time thermal anomaly detections | NASA FIRMS | --- ## 🔧 Project Architecture The codebase is organized cleanly to keep UI components, data parsers, and rendering logic modular: ```text src/ ├── main.js # Core bootstrap & Cesium viewport initialization ├── ui.js # Runtime interface elements, panels, and HUDs ├── mapStackController.js # Basemap switching and tile provider handlers ├── data/ # Layer-specific API integrations & pollers └── scenes/ # Cinematic camera controls and view sequences ``` --- ## 📋 License This project is open-source and available under the **[MIT License](LICENSE)**. ---
